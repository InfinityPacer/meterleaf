# 使用与报表

[返回首页](../README.md)

## 四个页面

| 页面     | 内容                                                         | 时间范围                                             |
| -------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| 用量总览 | 历史累计、账户额度、时段摘要、趋势与模型分布                 | 累计不受筛选影响；订阅额度按当前窗口；其余按所选时段 |
| 账户额度 | 周期百分比、重置时间、Tokens、请求数、估算费用与七天预估     | 有额度快照的账户按当前窗口；无快照账户显示历史累计   |
| 统计报表 | 模型分布与小时、天、周、模型、账户分组汇总                   | 按本页日期和筛选条件                                 |
| 请求明细 | 来源、模型、推理强度、账户、Token 数和费用；点击查看完整证据 | 按本页条件筛选并在服务端分页                         |

Web 总览中无额度快照的账户卡片展示所选时段用量；手机 App 首页优先展示该账户历史累计，缺少累计时才使用当前区间汇总。API 接入只表示接入方式；有快照时仍可展示订阅额度。

手机默认使用 App 模式，底部为首页、账户、统计、明细和我的。首页的时间段用量入口打开独立趋势页，微型趋势固定显示全账户近 30 天。可在“我的”中切换为侧栏模式；导航模式和主题会记住，重新打开仍然生效。

## 筛选与图表

快捷范围与自定义起止日期均支持；完整有效的日期修改立即生效，无需应用按钮。自然日和自然周按 `Asia/Shanghai` 统计。

各页面独立记住日期、模型、账户、图表选项及适用的汇总维度和排序。搜索关键词和分页不保存。

主题、USD 估算口径和账户顺序全局共享。主题可以跟随系统，也可手动选择明暗和配色。

支持 PWA 的浏览器可使用原生安装入口，将 Meterleaf 安装为独立窗口。断网后重新打开时只显示离线提示，不显示旧账本；恢复网络后刷新页面获取当前数据。

消耗趋势支持小时、天、周粒度，可切换柱状图、折线图和面积图；饼图展示模型占比，不表示时间变化。USD、Credits 和 Tokens 使用同一份报表结果切换。

## 账户管理

- 手工调整账户顺序后，总览卡片沿用该顺序；新账户追加在末尾。
- 归档账户默认不展示，可在账户页切换归档状态查看和恢复。
- 删除账户只移除账户展示，也可删除已归档账户；不会删除历史请求、累计统计或 Sub2API 数据。
- 可以在账户菜单中重命名账户，名称只在 Meterleaf 中显示，最长 40 个字，不会改动上游。清空名称或选择恢复原名后，重新显示上游提供的名称。
- 套餐徽标按使用倍数分三档显示，同一档外观相同。Claude Pro 与 ChatGPT Plus 为一档，Claude Max 5x 与 ChatGPT Pro 5x 为二档，Claude Max 20x 与 ChatGPT Pro 20x 为三档。无法识别的套餐只显示名称。
- 本地归档、删除状态和账户名称不会被同步覆盖。上游删除账户后，本地历史请求仍保留。

## 额度与金额

5 小时和 7 天窗口独立显示。窗口过期或没有有效快照时显示 `N/A`，不沿用上一周期统计；页面停留或从后台恢复时也会检查到期时间。

七天预估使用同周期截至快照采样时刻的消费除以已用比例，不要求多个采样。比例为零、缺失或窗口失效时不推算。快照可能包含其他入口的消费，而本地请求只覆盖已采集来源，因此预估不是供应商承诺额度。

Tokens 总量由普通输入、缓存读取、缓存写入和输出组成。推理 Tokens 是输出子集，不能再相加。缺失金额保留未知；可计价部分的合计不代表完整费用。两种美元口径和订阅 Credits 的区别见[计价说明](pricing.md)。

## 更新与失败提示

从右上角「数据同步」启动采集或开启自动同步。同步失败不会用演示数据替换已有账本。

后台刷新期间保留上次成功报表。首次查询没有缓存时仍需等待；读取失败与上游同步失败是不同问题，按提示中的阶段和错误编号排查，不要先清库。部署与日志操作见[部署指南](deployment.md)。

## 当前边界

请求详情按来源证据展示模型、推理强度、服务档位和耗时等字段，缺失字段不补默认值。当前尚不提供 CSV 导出、用户/API Key/网关分组统计、RPM/TPM、平均延迟或错误率报表。

Meterleaf 是独立用量账本，不是 Sub2API 管理面板的复刻；网关扣费与独立估值不能混为一个指标。
